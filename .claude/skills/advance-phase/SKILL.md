アイデア `$ARGUMENTS` の現在のフェーズを完了し、次のフェーズに進む。

## 手順

1. `ideas/$ARGUMENTS/README.md` を読み、現在のフェーズを特定する（🔄 のフェーズ）
   - 引数が空の場合は `ideas/` 配下の一覧を表示して選択してもらう

2. 現在のフェーズの完了チェック:
   - フェーズのドキュメントが存在し、内容が記載されていること
   - テンプレート（`_templates/`）の必須セクションが埋まっていること
   - **Phase 4 の形式判定**: `04-behavior/` ディレクトリが存在すれば新形式（ビヘイビア定義）、存在せず `04-requirements.md` があればレガシー形式（要件定義）として、対応する完了条件（`.claude/rules/phase-gate.md`）を適用する。両方存在する場合は新形式を正とし、不整合をユーザーに報告する
   - 未解決の疑問点が残っている場合はユーザーに確認する

3. 判定ゲートの処理（該当する場合）:
   - **Phase 1→2**: 追求判定 — PoCの価値があるかユーザーに確認
   - **Phase 3→4**: Go/No-Go判定 — PoC結果を踏まえて進行可否をユーザーに確認
   - **Phase 4→5**: スコープ確認 — ビヘイビアの範囲が妥当かユーザーに確認
   - **Phase 6完了**: 着手判定 — 実装を開始するかユーザーに確認
   判定結果は該当フェーズのドキュメント末尾に記録する（スコープ確認は新形式では `04-behavior/README.md` 末尾、レガシーでは `04-requirements.md` 末尾）

4. `README.md` のステータスを更新する:
   - 現在のフェーズ: 🔄 → ✅ 完了 + 更新日
   - 次のフェーズ: ⬜ → 🔄 進行中 + 更新日
   - ドキュメントリンクを追加

5. 次のフェーズに応じた作業を案内する:
   - **Phase 2（PoC計画）**: `01-brainstorm.md` の内容を踏まえて PoC計画を策定。`_templates/02-poc-plan.md` を参照
   - **Phase 3（PoC実施）**: `02-poc-plan.md` の計画に沿って各PoC項目を実施するよう案内。各PoC項目ごとに `03-poc/<item>/` ディレクトリを作成
   - **Phase 4（ビヘイビア定義）**: 全PoC結果を踏まえて画面・API ごとのビヘイビアを定義。`_templates/04-behavior/` を参照し、`ideas/<name>/04-behavior/` に README と項目ファイルを作成する。完了後は `/generate-spec <idea-name>` で仕様書 `spec.md` を生成できる
   - **Phase 5（タスク分解）**: 手順 2 の形式判定に応じて案内を分岐する。新形式ではビヘイビアをタスクに分解（`TASK-N`、「対象ビヘイビア」欄で ID を紐付ける）し `_templates/05-tasks.md` を参照。レガシー形式では要件をタスクに分解（`TASK-<要件番号>.<連番>` で `REQ-N` と紐付ける）し `_templates/legacy/05-tasks.md` を参照
   - **Phase 6（ロードマップ）**: タスクからロードマップを構築。`_templates/06-roadmap.md` を参照

6. Phase 6 が完了した場合、全体サマリーを生成してユーザーに提示する

## 注意事項

### 判定ゲートで No-Go / 保留 / 要戻しとなった場合

判定結果が「No-Go」「要縮小」「要追加PoC」「保留」となった場合、次フェーズへは進めない。以下の手順で前フェーズへ巻き戻す。

1. 判定結果と理由を、現フェーズのドキュメント末尾「判定」節に記録する。
2. `README.md` のステータスを更新する:
   - 戻り先のフェーズ: ⬜ / ✅ → **🔁 再検討中** + 更新日
   - 現在のフェーズおよび後続: 🔄 → **🔁 再検討中** / ⬜（内容は残す）
3. ユーザーに戻り先フェーズの再開方法を案内する（例: 追加 PoC の場合は `03-poc/<new-item>/` を作成）。
4. 中止が選ばれた場合は `README.md` ステータスを「❌ 中止」に更新し、要因を `01-brainstorm.md` に追記する。

詳細なフェーズ遷移ルールは [`.claude/rules/phase-gate.md`](../../../.claude/rules/phase-gate.md) を参照する。
