# 日本語ドキュメント規約

Ideas Repository 内のドキュメントは以下の規約に従って日本語で記述します。

## 基本方針

- 全てのドキュメント（`README.md`、`01-brainstorm.md` 〜 `06-roadmap.md`、エージェント・スキル定義、ガイド類）は日本語で書きます。
- コミットメッセージは日本語可（既存履歴に合わせる）。Conventional Commits の `type(scope):` は英字のまま。
- コード内コメントは日本語で書きます。ただし広く参照される OSS スタイルのコメントは英語可。

## 文体

- ドキュメント本文は **ですます調** で統一します（例:「〜します」「〜を行います」）。
- 見出し・箇条書きの末尾は体言止め・常体可（簡潔性を優先）。
- 命令・手順の Imperative は原形で書きます（「記録する」「確認する」）。

## 用語の統一

| 用語 | 採用 | 避ける |
|------|------|--------|
| アイデア | ◯ | アイディア／案 |
| フェーズ | ◯ | ステージ／段階 |
| 判定ゲート | ◯ | ゲート判定／チェックポイント |
| ブレスト | ◯（Phase 1 の短縮形） | 発散／ブレインストーミングの本文中略称 |
| ブレインストーミング | ◯（フェーズ正式名称・見出し） | ブレスト（見出しでは使わない） |
| PoC | ◯ | 概念実証（補足説明時のみ併記可） |
| ビヘイビア | ◯（Phase 4 の項目・ID 文脈） | 挙動／振る舞い（本文中の一般的説明では可） |
| ビヘイビア定義 | ◯（Phase 4 正式名称） | 要件定義（レガシー形式への言及時のみ可） |
| 要件 | ◯ | 仕様（要件と仕様を使い分ける場合は定義を明示） |
| タスク | ◯ | 作業項目 |
| マイルストーン | ◯ | 節目／区切り |
| ロードマップ | ◯ | 工程表 |

## ステータス記号

README.md のステータステーブルで使用する記号は [`convention.md`](./convention.md) の「ステータス記号」節を参照してください（`convention.md` を source of truth として一元管理します）。

## 表記の細則

- 半角英数字と日本語の間に半角スペースを入れません（例:「Claude Code で」「PoC の結果」）。
- ファイル名・コマンド・コード片は必ずバッククォートで囲みます（例: `ideas/<name>/01-brainstorm.md`）。
- 強調は太字 `**...**`。斜体は使いません。
- 数値や時間の単位は半角で書きます（例: `3日`, `YYYY-MM-DD`）。
