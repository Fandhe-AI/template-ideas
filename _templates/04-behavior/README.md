## ID 規約

- ビヘイビア ID は `<プレフィクス>-<番号>` とします（例: `LOGIN-1`）。プレフィクスは各ファイル冒頭で宣言し、このアイデア内で対象領域と 1:1 に対応させます。
- 番号はファイル内の通し番号です。**削除しても再利用しません**（欠番のまま残す）。新規項目はファイル内の過去最大値 +1 を使います。
- ステータスは「確定 / 検討中」の 2 値です。
- 優先度は Must / Should / Could を付与します。Won't 相当は項目化せず本ファイルの「除外事項」に記載します。
- 各項目は検証可能な形（**前提 / 操作 / 期待**）で書きます。
